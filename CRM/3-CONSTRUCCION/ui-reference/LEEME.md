## Estilo (tipo "Excermol")
- **Layout:** sidebar izquierda + pipeline Kanban (columnas con borde de color arriba).
- **Tarjetas:** logo/inicial + nombre + monto (píldora verde) + tag de color + reloj + fecha + avatares + 3 botones (llamar/mensaje/perfil).
- **Colores:** indigo `#6d5ef0` · teal `#12b3a6` · navy `#0e1630` · fondo `#f6f7fb`.
  Etapas: Nuevo (indigo) · Interesado (azul) · Cita (ámbar) · Negociación (teal) · Cerrado (verde).
- **Tipografía:** Inter (400–900).
- **Sensación:** limpio, premium, simple para las asesoras. Menos es más.
