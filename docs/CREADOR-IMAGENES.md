## 🧾 FORMATO DE SALIDA (Opus produce esto por cada creativo)
Un objeto `cfg` (el motor lo convierte en imagen 1080×1920). Ejemplo:
```json
{
  "angulo": "Testimonios",
  "img": "DSC00908.JPG",
  "fy": 0.4,
  "kicker": "HISTORIAS REALES",
  "h1": "Aquí mis nietos aprendieron a nadar",
  "sub": ["Familias que ya viven frente al Pacífico,", "en la Riviera Pacífica de Panamá."],
  "price_text": "$193,912 USD",
  "trust": "3,500+ FAMILIAS · 23 AÑOS",
  "cta": "Agenda tu visita →",
  "out": "testimonio_01.png"
}
```
**Reglas del cfg:**
- `img` = nombre exacto de una foto del zip (Opus elige).
- `price_text` = SIN la palabra "Desde" (el motor la antepone).
- `sub` = lista de 1-2 líneas.
- `h1` corto y potente (≤ ~6 palabras idealmente).
- `cta` con flecha "→". `out` = nombre único por creativo.
- Para **objetivo formulario**: CTA tipo "Déjanos tus datos →" / "Agenda tu visita →".
- Para **objetivo web**: CTA tipo "Conoce los planes →" / "Ver precios →".
